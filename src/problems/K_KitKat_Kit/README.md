# K. KitKat Kit

## Условие (кратко)
Нужны числа `k1 > k2 > … > kn > 0` такие, что для каждой тройки `a < b < c` из списка
выполнено `k_a < k_b + k_c`, и `k1` минимально.

## Переход к разностям
Пусть `d_i = k_i − k_{i+1} ≥ 1` при `i < n` и `d_n = k_n ≥ 1`. Тогда `k_1 = Σ d_i`,
а условие тройки:

```
d_a + … + d_{b−1}  <  d_c + … + d_n
```

Слева — отрезок до `b`, справа — суффикс от `c` (они не пересекаются, так как `b < c`).

## Ключевое наблюдение
Посмотрим, кому помогает увеличение какого `d_i`:
- `d_n` входит в **правую часть каждого** условия и ни в одну левую. Его увеличение
  помогает всем условиям и никому не мешает;
- любое другое `d_i` может кому-то помочь, а кому-то помешать.

Возьмём любое решение и перенесём весь «излишек» `d_i − 1` (при `i < n`) в `d_n`.
Сумма (то есть `k1`) не изменится, а каждое условие останется выполненным. Значит,
оптимум достигается при `d_i = 1` для `i < n` и `d_n = K`, то есть `k_i = n − i + K`.

Тогда условие тройки превращается в `b − a + c − n < K`, и

```
K = max(1, max по тройкам (b − a + c − n) + 1)
```

## Сложность
`O(n + m)`.
