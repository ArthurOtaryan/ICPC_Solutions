# C. Cable Network

## Условие (кратко)
Даны `n` различных точек на плоскости. Нужно соединить их `n − 1` отрезками в дерево так,
чтобы отрезки не проходили через другие точки, не пересекались (кроме общих концов)
и между любыми двумя точками был путь не длиннее 4 отрезков. Либо сказать `NO`.

## Идея
**Все точки на одной прямой.** Отрезок не может перепрыгнуть через точку, поэтому дерево —
только путь вдоль прямой. Его диаметр `n − 1`, значит ответ `YES` тогда и только тогда,
когда `n ≤ 5`.

**Иначе ответ всегда `YES`.** Строим дерево глубины ≤ 2 от некоторого центра `X`
(тогда любые две точки на расстоянии ≤ 4).

1. Пусть `c` — самая нижняя (затем самая левая) точка, а `X` — ближайшая к `c` точка на
   каком-нибудь луче из `c`. Если смотреть из `X`, на луче в сторону `c` лежит ровно одна
   точка — сама `c` (за ней точек нет, ведь `c` крайняя).
2. Сортируем все точки по углу вокруг `X` и группируем по лучам.
3. `X` соединяем с ближайшей точкой каждого луча — получается «звезда» без пересечений.
4. Остальные точки луча соединяем с ближайшей точкой **соседнего** луча. Отрезок между
   двумя соседними лучами лежит внутри сектора между ними. Если угол сектора < π, внутри
   нет других точек, и отрезки из одного сектора расходятся веером из одной точки.
5. Каждый сектор должен использовать только один луч. Луч с `c` (одна точка) разрывает
   цепочку: лучи до него «смотрят» вперёд, лучи после — назад. Если есть сектор с углом
   ≥ π, начинаем цепочку сразу после него.

## Почему это верно
- Глубина от `X` не больше 2, значит диаметр дерева не больше 4.
- Звёздные отрезки лежат на разных лучах.
- Дополнительные отрезки лежат внутри своих выпуклых секторов, по одному лучу на сектор.

## Сложность
`O(n log n)` — сортировка по углу; все вычисления в целых числах (векторное произведение).
