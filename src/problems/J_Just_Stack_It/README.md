# J. Just Stack It

## Условие (кратко)
Есть `n` дисков. На стержень помещается не больше `k` дисков, размеры на стержне строго
возрастают сверху вниз. Нужно минимальное число стержней и сама раскладка.

## Нижняя оценка
- Одинаковые диски обязаны лежать на разных стержнях → стержней ≥ максимальная
  кратность размера `mx`.
- На стержне ≤ `k` дисков → стержней ≥ `⌈n / k⌉`.

`r = max(mx, ⌈n / k⌉)`.

## Конструкция (достигает оценки)
Сортируем диски и раздаём по кругу: диск с номером `i` кладём на стержень `i mod r`.

- Одинаковые размеры идут подряд блоком длины `≤ mx ≤ r`, поэтому попадают на разные
  стержни, а на каждом стержне размеры строго возрастают.
- На каждый стержень попадает `≤ ⌈n / r⌉ ≤ k` дисков.

## Сложность
`O(n log n)`.
