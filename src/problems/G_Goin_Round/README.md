# G. Goin' Round

## Условие (кратко)
На кольце из `n` клеток стоят тележки. Игроки по очереди двигают одну тележку по часовой
стрелке, не обгоняя другие. Выигрывает тот, после чьего хода появилось `g` пустых клеток
подряд. Нужно определить исход: `Anya`, `Borya` или `Draw`.

## Переход к промежуткам
Пусть `G[0..c−1]` — длины пустых промежутков между соседними тележками. Ход тележкой
переносит `k ≥ 1` пустых клеток из промежутка `i` в предыдущий промежуток `i − 1`.

- Игрок **выигрывает сразу**, если есть два соседних промежутка с суммой
  `G[i] + G[i+1] ≥ g`: он сдвигает тележку между ними до упора.
- Ход **безопасен**, если после него все суммы соседних пар `< g` (иначе соперник сразу
  выиграет). Из промежутка `i` безопасно ходить (достаточно `k = 1`) ⇔
  `G[i] ≥ 1` и `G[i−2] + G[i−1] ≤ g − 2`.

## Ответ
1. `c = 2`: сумма пары всегда `n − 2`. Если `n − 2 ≥ g` → `Anya`, иначе никто не победит → `Draw`.
2. Есть пара с суммой `≥ g` → `Anya` (выигрывает первым ходом).
3. У Ани нет безопасного хода → `Borya`.
4. У Ани есть безопасный ход, после которого у Бори нет безопасных ходов → `Anya`.
5. Иначе → `Draw`.

Это свойство (исход определяется первыми двумя ходами) **проверено полным ретроградным
анализом игры для всех позиций с n ≤ 13** — расхождений нет. Строгого доказательства
в разборе нет.

## Реализация
Перебираем все ходы `(i, k)`: их `Σ G[i] ≤ n`. После хода меняются только индексы
`i−1 … i+2`, поэтому счётчик безопасных ходов пересчитывается за `O(1)`.

## Сложность
`O(n)`.
