# E. Efficient Packing

## Условие (кратко)
Контейнер `W × H × D` и до 4 коробок. Коробки можно поворачивать (рёбра параллельны осям).
Нужно разместить их без пересечений с целыми координатами или сказать `NO`.

## Идея
Две коробки не пересекаются ⇔ они разделены хотя бы по одной оси
(одна целиком левее/ниже/ближе другой).

Перебираем:
1. **ориентацию** каждой коробки — 6 вариантов, всего ≤ 6⁴ = 1296;
2. для каждой пары коробок — **ось**, по которой они разделены: 3 варианта на пару,
   пар ≤ 6, всего ≤ 3⁶ = 729.

Для каждой оси получается граф «эти коробки должны идти друг за другом вдоль оси».
Направим рёбра по какой-нибудь перестановке коробок и поставим каждую коробку сразу за
предыдущими (координата = максимальный правый край предшественников). Тогда нужная длина
вдоль оси = самый тяжёлый путь. Должно получиться `≤` размера контейнера.

## Ускорение
Результат по оси зависит только от того, какое измерение каждой коробки направлено вдоль
оси (3⁴ = 81 вариант), и от множества рёбер (2⁶ = 64). Заранее считаем
`T[выбор][маска]` = минимум по 24 перестановкам. Тогда основной перебор
1296 × 729 ≈ 10⁶ проверок.

## Почему это верно
Любую корректную упаковку можно «прижать» к началу координат по каждой оси, не нарушая
разделений. Это ровно та расстановка, которую строит алгоритм. Значит, если упаковка
существует, перебор её найдёт. Это работает и для «неразрезаемых» упаковок, как в
4-м примере.

## Сложность
≈ 10⁶ простых операций.
