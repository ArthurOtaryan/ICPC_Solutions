# D. Divide and Count

## Условие (кратко)
Лист бумаги разрезают по двум окружностям. Сколько получится кусков?

## Идея
Пусть `d` — расстояние между центрами. Разбираем случаи:

| Расположение | Куски | Почему |
|---|---|---|
| Окружности совпадают | 2 | один разрез: круг и остальное |
| Пересекаются в двух точках: `|r1 − r2| < d < r1 + r2` | 4 | «линза», два «полумесяца», внешняя часть |
| Все остальные (не пересекаются, касаются, одна внутри другой) | 3 | |

Касание в одной точке куски не разделяет: две области, касающиеся в точке, — это два
разных куска, но новый кусок не появляется.

## Реализация
Чтобы не работать с корнями, сравниваем квадраты в целых числах:
`(r1 − r2)² < d² < (r1 + r2)²`.

## Сложность
`O(1)` на тест.
