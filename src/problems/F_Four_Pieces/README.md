# F. Four Pieces

## Условие (кратко)
Есть `n` скобочных строк. Сколькими способами можно выбрать упорядоченную четвёрку строк
(с повторами), чтобы их конкатенация была правильной скобочной последовательностью?

## Идея
**Сжатие строки.** Любая скобочная строка после сокращения пар `()` превращается в
`)^c (^o`, где
- `c` = −(минимальный префиксный баланс) — сколько «лишних» закрывающих;
- `o = c + баланс` — сколько «лишних» открывающих.

**Условия для `s1 s2 s3 s4`:**
- у `s1` нет лишних `)` (`c1 = 0`), а у `s4` нет лишних `(` (`o4 = 0`);
- `c2 ≤ o1` (вторая строка не уводит баланс в минус), и после двух строк баланс
  `P = o1 + b2`;
- симметрично справа: `o3 ≤ c4` и `c4 − b3 = P`.

Значит, ответ:

```
ответ = Σ_P  A[P] · D[P]
```

- `A[P]` — число пар (`s1`, `s2`) с балансом `P` посередине;
- `D[P]` — то же для пар (`s3`, `s4`). Это та же задача, если развернуть строки и
  поменять `(` ↔ `)`.

**Как быстро посчитать `A`.** Перебираем различные значения `x = o1` по возрастанию и
добавляем в счётчик по балансам строки с `c2 ≤ x`. Затем для каждого встреченного баланса
`b` делаем `A[x + b] += U(x) · cnt[b]`.

## Почему быстро
Строка с балансом `±v` или с `o1 = x` имеет длину не меньше `v` (или `x`). Сумма длин
≤ 2·10⁶, поэтому различных значений всего `O(√L)` ≈ 2000. Двойной цикл — `O(L)`.

## Сложность
`O(n log n + L)`.
