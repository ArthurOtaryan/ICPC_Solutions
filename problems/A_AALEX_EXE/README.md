# A. AALEX.EXE

## Условие (кратко)
Дан отсортированный список DOS-файлов `ИМЯ.РАСШ` (имя до 8 букв, расширение до 3).
Ровно один файл имеет расширение `EXE`. Разрешено дописать в начало его имени несколько
букв `A` (если имя стало длиннее 8 символов — обрезать до первых 8). Нужно минимальным
числом букв сделать этот файл первым в списке или сказать `IMPOSSIBLE`.

## Идея
Достаточно перебрать количество добавленных букв `k = 0, 1, …, 8`.
При `k ≥ 8` имя всегда превращается в `AAAAAAAA`, поэтому дальше перебирать бессмысленно.

Для каждого `k`:
1. строим новое имя `("A" * k + имя)` и обрезаем до 8 символов;
2. сравниваем `(имя, расширение)` со всеми остальными файлами;
3. если новое имя строго меньше всех — это ответ (первый найденный `k` минимален).

## Почему это верно
- Сравнение имён в задаче — обычное лексикографическое, где префикс меньше более
  длинной строки. Ровно так работает `String.compareTo` в Java.
- Если имена равны, сравниваются расширения.
- Добавлять буквы можно только в начало, поэтому все возможные имена — это ровно
  9 вариантов для `k = 0..8`, и перебор их всех даёт полный ответ.

Пример `IMPOSSIBLE`: в списке есть `A.TXT`. Любое наше имя начинается с `A` и длиннее,
значит `A` — его префикс и всегда стоит раньше.

## Сложность
`O(9 · n)` сравнений строк длины ≤ 8 на тест.

## Запуск
```bash
javac A.java
java A < input.txt
```
